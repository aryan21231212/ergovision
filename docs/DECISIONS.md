# Architectural & Technical Decisions (DECISIONS.md)

This log contains finalized, binding decisions for ErgoVision. These decisions are locked to preserve speed and avoid re-litigation during the 30-hour build window.

| Decision ID | Area | Decision | Choice Locked | Rationale & Alternatives Rejected |
|---|---|---|---|---|
| **DEC-001** | Platform Stack | Native Android (Kotlin) | Kotlin + Android SDK | Rejected Flutter/React Native/PWA. Native provides zero-bridge overhead, direct access to CameraX 1.5 frame-rate controls, MediaPipe Tasks, LiteRT-LM C++/AAR bindings, and foreground services. |
| **DEC-002** | Camera Capture | CameraX 1.5.0+ SessionConfig Throttling | ~5 FPS ImageAnalysis + RGBA_8888 | Throttled to ~5 FPS to avoid thermal throttling on the Adreno GPU/NPU. Using `RGBA_8888` eliminates CPU-bound YUV-to-RGBA conversion overhead required by MediaPipe. |
| **DEC-003** | Frame Gating | Manual Fallback Hardware Gate | Timestamp Delta Gate (>= 200ms) | If hardware HAL ignores the CameraX 1.5 SessionConfig target FPS, drop frames manually if `elapsedRealtime() - lastFrameTime < 200ms`. Excess `ImageProxy` instances are closed immediately. |
| **DEC-004** | Pose Estimation API | MediaPipe Tasks Vision PoseLandmarker | `pose_landmarker_lite.task` on GPU delegate | The "lite" task model balances sub-15ms inference latency and spatial accuracy at 5 FPS. GPU delegate is stable on Qualcomm Adreno. Do not attempt live Hexagon NPU QNN cross-compilation during the hackathon. |
| **DEC-005** | UI Orientation | Static Screen Orientation | `screenOrientation="portrait"` locked in Manifest | Known MediaPipe GPU delegate bug causes native crashes on dynamic surface re-configuration during runtime rotation. Locking orientation in Manifest eliminates this risk. |
| **DEC-006** | Coordinate Space | 3D World Landmarks | MediaPipe World Landmarks (meters) | Replaced 2D normalized coordinates. 2D coordinates distort angles due to camera focal length and perspective skew. 3D world landmarks provide metric, hip-relative vectors suitable for standard ergonomic trigonometry. |
| **DEC-007** | Posture Methodology | Ergonomic Assessment Model | REBA-inspired Vector Trigonometry | RULA is limited to upper-body work. REBA covers trunk, neck, and upper limbs. Full clinical REBA is rejected (requires load/coupling weights); simplified REBA geometric angular thresholds are used. |
| **DEC-008** | Hazard Debounce Logic | Time-Based Median Sliding Window | 5.0-second Rolling Timestamp Window | Frame-count buffers fail when camera FPS dynamically drops under thermal load. A time-based window computing median risk score prevents single-frame occlusion anomalies from triggering false alarms. |
| **DEC-009** | LLM Engine | On-Device Inference Runtime | LiteRT-LM (`litertlm-android`) | MediaPipe LLM Inference API is deprecated. Raw llama.cpp/JNI requires fragile NDK cross-compilation under time pressure. LiteRT-LM is Google's supported edge runtime with first-party Kotlin bindings. |
| **DEC-010** | LLM Model Target | Model Family Selection | Llama 3.2 1B (Fallback: Gemma3-1B) | 1B parameter models execute at 40+ tokens/sec on modern Snapdragon chipsets. If Llama 3.2 1B conversion fails during pre-test, Gemma3-1B is the locked fallback. |
| **DEC-011** | Voice Alert Tiering | Two-Tier Alert System | Tier 1: Hardcoded Template Alert; Tier 2: Async LLM | Real-time alerts must never block on LLM inference latency. Hardcoded template sentences execute immediately via offline TTS (<50ms). LLM runs asynchronously post-incident for detailed coaching. |
| **DEC-012** | Storage & Privacy | Privacy-by-Architecture | Room Database (Events only) | Zero frame or video persistence. No network permissions (`INTERNET` excluded). SQLite/Room stores only structured event metadata (`timestamp`, `hazardType`, `peakScore`, `duration`). |
| **DEC-013** | Office Kit Bridges | Multi-Touchpoint Integration | Remote Control + Screen Mirror + Clipboard + File Transfer | Remote Control drives Red Light builds. Screen Mirror provides jury visualization. Shared Clipboard transfers weekly reports to laptop. File Transfer exports Room CSV files. |
